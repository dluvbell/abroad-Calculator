💡 핵심 연산 매커니즘 (정정 통합본 v2)

• 수익률 모형(몬테카를로): 자산 성장은 로그정규분포 factor = exp(N(μ, σ))로 산출됩니다. 입력 성장률 μ는 중앙값(기하) 실질 드리프트로 해석되어 변동성 드래그로 인한 중앙값 처짐이 제거되며, 수익 팩터는 항상 양수입니다(자산 음수 방지).

• 배당/분배 모형: 분배율은 NAV에 대해 일정 비율로 고정됩니다(절대 배당금은 NAV 성장으로 자동 증가). '배당 성장률'은 수익률을 복리로 부풀리지 않고 해당 슬리브의 연 가격 드리프트에 가산됩니다.

• 비거주자 과세: 태국으로 송금(지출 충당)된 돈에 과세 — 「현지 과세」 인컴 + 송금 배당 + 자산 매각분 중 차익(gain)만. 풀 단위 원가추적으로 매각액의 차익비율만 과세하고 원금 회수분은 비과세(조약 비과세 인컴도 제외). 각 인컴은 Gross CAD × (1−캐나다원천%) 실수령. 배우자 포함 시 인컴은 귀속대로, 자산 유래 과세 송금은 부부 50/50로 나눠 태국 누진세 2회 분리 → 평탄화 최적. 말레이시아는 FSI 비과세 시 0.

• FX 리스크: 몬테카를로는 환율을 로그정규 랜덤워크로 진화시켜 통화 불일치 리스크를 반영합니다(심플은 연 추세만 적용).

• 시작 정렬(t0): 초기자산 합계를 목표비중으로 정렬 후 시작합니다. 연산 순서: 가격변동 → 배당확정 → (실수령인컴→배당→원금) 지출충당 → 송금 인컴·배당 과세(배우자 분리) → 잔여배당 재투자 → 인컴잉여 가산 → 목표비중 강제 리밸런싱.
